# Solutions

Human-readable views of the experiment outputs.

- **[`by-task/`](by-task/)** — for each of the 75 tasks: the problem, the reference answer, and **every model's full solution** with the automated judge's score (answer correctness, solution validity 0–3, error type). One file per area, models in collapsible `<details>` blocks:
  - [Differential Equations (DE)](by-task/DE.md)
  - [Probability & Statistics (MS)](by-task/MS.md)
  - [Number Theory & Combinatorics (NT)](by-task/NT.md)
  - [Discrete Mathematics & Logic (DM)](by-task/DM.md)
  - [Mathematical Methods (MM)](by-task/MM.md)
- **[`best-solution-per-task.md`](best-solution-per-task.md)** — for each task, one full correct (highest-validity) model solution, as a readable answer-key supplement.

Raw machine-readable data is under [`../data/`](../data); aggregate tables under [`../results/tables`](../results/tables).
