# Solutions / Решения

[← Main README](../README.md) · [← Главный README](../README.ru.md)

## English

Human-readable views of the experiment outputs.

- **[`by-task/`](by-task/)** — for each of the 75 tasks: the problem, the reference answer, and **every model's full solution** with the automated judge's score (answer correctness, solution validity 0–3, error type). One file per area, models in collapsible `<details>` blocks:
  - [Differential Equations (DE)](by-task/DE.md)
  - [Probability & Statistics (MS)](by-task/MS.md)
  - [Number Theory & Combinatorics (NT)](by-task/NT.md)
  - [Discrete Mathematics & Logic (DM)](by-task/DM.md)
  - [Mathematical Methods (MM)](by-task/MM.md)
- **[`best-solution-per-task.md`](best-solution-per-task.md)** — for each task, one full correct (highest-validity) model solution, as a readable answer-key supplement.

Raw machine-readable data is under [`../data/`](../data); aggregate tables under [`../results/tables`](../results/tables).

## Русский

Человекочитаемые представления результатов эксперимента.

- **[`by-task/`](by-task/)** — для каждой из 75 задач: условие, эталонный ответ и **полное решение каждой модели** с оценкой судьи (правильность ответа, валидность решения 0–3, тип ошибки). По файлу на раздел, модели — в раскрывающихся блоках `<details>`:
  - [Дифференциальные уравнения (DE)](by-task/DE.md)
  - [Теория вероятностей и статистика (MS)](by-task/MS.md)
  - [Теория чисел и комбинаторика (NT)](by-task/NT.md)
  - [Дискретная математика и логика (DM)](by-task/DM.md)
  - [Математические методы (MM)](by-task/MM.md)
- **[`best-solution-per-task.md`](best-solution-per-task.md)** — по одному полному верному решению (с наивысшей валидностью) на каждую задачу — как дополнение к ключу ответов.

Сырые машиночитаемые данные — в [`../data/`](../data); сводные таблицы — в [`../results/tables`](../results/tables).
